# GoldCamp｜持续开发到朋友试玩雏形：启动包 v0.3

## 这是什么

这是根据用户最新要求整理的**当前任务补充基线＋规则默认值＋原始图片参考**，不是新建 Unity 工程，不是已经制作好的 3D 资产，也不是完成报告。普通设计细节由助手按用户本次授权给出可修改默认值，不再逐项等待确认。用户明确要求：**营地永久保留，有存档，退出后继续，不做每局重开的游戏。**

本轮目标是可以持续改进的朋友试玩雏形：有一段完整成长、真实多人玩法和可辨认的卡通画面，不要求一次达到商业发行品质。不能只交拾方块测试，也不能把全部远期脑洞一次性展开。

## 文档关系与冲突

- 当前任务遵守系统与工具权限，以及用户最新明确要求。v0.3 只覆盖原案的相关规则与当前交付范围，不作无限授权。
- 原 v0.1 保留为总体设计、远期路线和历史基线；v0.2“待确认清单”不再是本轮需要重新发给用户填写的问卷。
- `AGENTS.md` 若仍写“仅 M0”，应按当前授权更新为长期规则＋当前任务入口；不能继续用过期阶段禁止网络、采矿、存档。
- 图片决定视觉参考，不自动新增规则；文本玩法和本轮范围优先于图上的标签、箭头、矿区数量和道具暗示。
- 实际代码、版本、测试、构建和 Git 是**完成事实**的依据；策划文档不能证明实现。
- 复用现有活动分支与在做的工作。若 Prototype01 已在本机执行，将它纳入本轮连续任务，不另开写入者重做。

## 本轮相对原案的明确变化

1. 将原 M1、M2 和必要 M3 内容串成一个持续任务，内部逐段验收，无需用户为每个小功能发新 Prompt。不是要求不分阶段，也不是将原 M4—M6 一起做完。
2. 明确持久营地、个人财产、矿坑改变、梯子和区域解锁均需保存；第一次正常游玩不得默认新开档。
3. 角色采用用户提供的绿色卡通矿工参考，不沿用早期真人矿工海报或职业属性设计；外观无职业加成。
4. 原“矿点产物”扩充为**有限范围可真实挖空的块状矿坑＋梯子＋一种修理/升级循环**，不是全地图无限挖掘。
5. 新增**一个付费进阶采区和一辆简化可驾驶四座运输车**作为成长样段，不做四个大矿区和真实车辆模拟。
6. 用户此前对赌桌选项未删净，但本次已授权合理定规则；默认纳入一张最简单的两人原石对赌桌，其他人可围观。
7. 吸烟、喝酒表演和基础游戏内语音在范围内；吞咽/厕所留到后续。未授权新增付费，预算按 0 执行。
8. 最终异网联机仍是要求，不以本机四进程冒充。Steamworks/AppID 未知是外部条件，不是自动延期或擅自付费的理由。
