# 四张参考图怎么用于这轮开发

四图是用户提交的设计参考，原图原样复制，无裁剪、改画或自动生成的新版本。它们都是 PNG 图片，不是已经存在的网格、材质、骨骼或 Unity 场景。

## 2. 参考冲突的具体处理

### 角色

四人使用同一物种/基底模型，改帽色、外套色和少量配件；没有力量型/侦察型等固定属性。用户给的角色不是需要识别名称的既有人物，不用绑定任何现成动画角色IP。

可以简化衣缝、污渍和面数，但不能为了套通用人类资产把它换回大胡子真人。躯干与头连接方式按图处理；若通用人形骨架不合适，用简化自定义骨架，不人为加长脖子。

手要能拿镐/探测器/瓶子，大矿握点和嘴部挂点明确。正面/侧面/背面细节有小不一致时，按主要轮廓和可制作性统一并记录，不陷入逐像素争论。鼓嘴和吸烟/喝酒要使用同一个角色，不能只有概念图片。

### 镜头

地图和营地图片是鸟瞰参考；实际玩法维持第一人称。关卡高度、遮挡、台面和人物比例必须在第一人称验证，不能直接把俯视图铺成背景平面冒充场景。

### 地图

中心营地的四栋房子保留，但原草图的西/北/东/南矿区作为远期方向。本轮实现附近初级坑＋短车路另一端的进阶小坑，其余用自然远景或明确封闭处理。

解锁进阶区走真实地面道路，不把车开过概念图上不存在车宽的木桥。可以调整桥、道路和出入口；保留中心营地与多路探索的感觉，不照搬不可玩的几何关系。

图中的“隐藏矿点”标签只供开发理解，玩家HUD不能直接展示其坐标。金光用于部分已露矿/稀有发现，不把整个环境装饰得都是可采金币。

### 不采用的额外推断

以前助手的组合海报只算候选，尤其是职业称号、四级矿区、所有湖泊可探索、工厂链等文字不构成确认。优先使用这四张用户原图＋v0.3规则。

## 3. 素材落地的最小验证

先做一个矿工、矿镐/探测器、木屋/台面、岩石/树组成的小样，放进游戏真实灯光中检查。确认这些对象能以相同视觉语言共存，再批量做四配色和场景模块。

每项正式进入玩法的资产都要有：实际3D文件或可复现生成脚本；正确尺度/坐标；材质；合适碰撞；必要挂点；可用动画/形变（适用时）；Prefab；游戏内和Windows包验证。

本轮不要求逐像素复刻，也不要求先生成额外几十张概念图。不能把静态三视图转换成卡片/立绘当成3D角色，不用大片白盒称作匹配参考。小样未达到方向就修改轮廓和材质，不增加无关华丽特效掩盖。

参考图属于设计输入，保留在非运行时参考目录；Unity只导入实际使用的资产。来源登记写“用户提交的设计参考”，不伪造素材购买许可或商标清查结论。新增第三方资产才登记实际许可，不做与本轮无关的版权审计。

## 4. 图像工具缺失时

必须先尝试当前本地可用的图像查看方式。若确实看不到图，说明哪些没有看过，可以依据本文件描述继续非视觉部分；不要谎称“已逐张查看”。这时外观精确验收保留待核对，不改成自己喜欢的另一套风格。

用户不需要先把图片转换成 FBX/GLB。制作转换、程序建模、装配和测试是本次开发工作，而不是再次推给用户的前置清单。
