# GoldCamp／淘金营地 · 朋友试玩说明

> **局域网候选说明｜2026-09-06**。成长与车辆已完成本机双进程正常采集、升级、修车、进阶运矿和重开验证；这仍不是“完整验收通过”的发布说明。语音与显示设置已进入实际构建，本机双进程麦克风、编码传输与DSP播放、静音和距离过滤已实测；真人听感仍待双方实际对话。两台电脑的局域网连接、异网双向语音、四名真人及中美组合、完整一小时键鼠体验均待实测。具体包版本与验证范围见包内清单；没有两台设备的连接证据时，先按下文验证LAN。

## 先把游戏打开

1. 从制作者取得**同一版本的完整 ZIP 包**，解压到自己的普通文件夹，不要在压缩包预览里直接运行。
2. 打开解压后的 `Windows/GoldCamp.exe`。旁边的 `GoldCamp_Data`、`UnityPlayer.dll`、`MonoBleedingEdge`、`Licenses` 等文件必须一起保留；只发一个 exe 不能运行。
3. 不需要安装 Unity 或 Unity Hub。这个候选使用本地地址加入，不需要朋友购买游戏、服务器或额外服务；本轮不付款、不公开发布。
4. 每位朋友使用自己的电脑和 Windows 用户资料，一次只开一份游戏。先留好包内 `Windows/build-info.json` 与根目录 `manifest.json`，报告问题时用它们确认版本。

本房间最多 **4 人，包含房主**。如果制作者加四位朋友一共五人，请轮换一位；不要把同一电脑开的四个窗口记成四名真人试玩。

## 房主建营地，朋友加入

房主先填昵称，点击“继续上次营地”。第一次没有存档时，按提示选择“新建独立营地”；新营地是另一份世界，不覆盖旧营地。当前“继续”打开最近保存的营地，菜单还没有旧营地列表选择器；想回到更早的营地时先联系制作者，不要删档试错。

其他人先等房主进入世界，再在主菜单的“房主地址”框填**房主当前连接网络的真实 IPv4 地址**，点击“加入营地”。房主可从 Windows 当前 Wi-Fi／以太网连接的属性里查看 IPv4。地址通常形如 `192.168.x.x`，这里只是格式示例，不能照抄。

- 当前候选只供已有同一局域网条件下尝试，连接成功仍需两台真实电脑核验。
- 默认端口为 **7770**。界面目前只有地址输入框，没有端口设置；这里填纯地址，不加 `:7770`。
- 默认显示的 `127.0.0.1` 只指向正在运行游戏的这台电脑，另一台电脑用它找不到房主。
- 房主必须保持游戏和营地会话开启。房主离开后会话结束，不会自动换一位朋友接管。
- 连接失败时保留屏幕提示，记录双方版本、时间和网络条件交给制作者。本说明不要求调整防火墙、路由器或安装 VPN／组网工具。

当前没有可用的 Steam 好友邀请、房间码、二维码或公开匹配入口。Steam 接入仍需项目本人核对真实 AppID、账户权限与朋友的测试访问，之后再验证异网连接；这些条件尚未确认，不等于已确认项目没有 AppID，也不能用示例 AppID 冒充本项目分发。不能把地址输入框当成已具备互联网邀请功能；本次不要求朋友购买 Steam 访问或第三方服务。Steam 的测试访问说明见 [Steam 官方测试说明](https://partner.steamgames.com/doc/store/testing)。

## 这个营地会留下什么

营地是房主电脑上的永久世界：挖开的两个矿坑、梯子、各人的钱与工具升级、个人柜、车辆及货物、公共贡献与解锁、原石和赌局结果都随营地保存。没有回合倒计时、每日清空或强制债务；玩一小时只是这次聚会的安排。房主不在时世界不继续运行，也没有云存档或房主迁移。

你的身份来自本机保存的身份资料，**不是昵称**。改名不会让你变成另一个账户，起同名也不能领走别人的钱。换电脑或删除身份资料可能被当成新玩家；不要为了解决连接问题删除这些文件。财产属于当前营地，去另一个房主的世界不会自动带上原世界的财富。

离开前分清三种情况：

| 操作 | 随身矿物怎样处理 | 哪些长期财产保留 |
| --- | --- | --- |
| 非房主单独离开或断线 | 普通手持、口袋和嘴槽货留在原处公共掉落包；沉重大矿单独落地。别人可取，重连不会再补发一份 | 余额、个人柜、工具与升级 |
| 房主正常“保存并结束会话” | 保存当时仍在线玩家的随身状态，下次继续；已经先离开的玩家仍按上面的留包规则处理 | 整个营地的已保存进度 |
| 菜单“返回营地”脱困 | 约 4 秒引导，未入柜战利品留在原地，不能借此把矿运回家 | 余额、个人柜、工具与升级 |

**个人柜是安全保管处；公共地面、掉落包、桌边和车货架不是。** 击晕、搜袋不能拿走你的余额、基础工具、升级或柜内收藏。别人替你卖了货，钱会进实际卖家的账户，分账要由卖家主动转账。

自动保存约每 30 秒一次，关键交易成功前会保存结果。按 `Esc` 可以看“最近保存”时间。正常结束请用菜单里的保存退出；若提示保存失败，先留在游戏里并报告，不要把失败当成已保存。异常关机或崩溃仍可能丢掉最近未保存的活动，不能保证断电零损失。

设置在 `Esc` 菜单中：音效、环境和语音分别调音量；“显示与舒适度”提供窗口分辨率、无边框全屏，以及默认关闭的“轻微行走镜头摇晃”。选分辨率后点“应用窗口设置”；其余可点“保存当前设置”。试玩中头晕就先停下、关闭镜头摇晃并调整视野；卡顿请记录分辨率和出现位置，目前没有已验证的最低配置或稳定 60 帧承诺。

## 第一趟采矿和分账

营地里有收购台、维修台、原石加工台、原石对赌桌、四处个人柜，以及旧车旁的公共维护点。初级矿坑在营地北侧，进阶采区沿车道继续向北；远景和道路、营地地基不能随意挖。

先按 `2` 用左键探测，再按 `1` 开挖眼前露出的岩层。挥镐前把手中矿放下或收入口袋，并离开梯子。矿格会真正挖空，人可以进入；不能隔着完整岩层直接挖更深处。默认初级坑是 **144 格**，不会因退出或卖完矿自动填回。

每人起始有 2 段梯子。先给入口空格装上段，再逐格往下延伸；两段梯子能连接两层。拆除要从最下段开始，正在使用或支撑下段的梯子不能拆。带大矿也可慢慢沿完整梯路返回。坑口保留一侧完整地面作为出口，不要一口气把自己的回程都挖掉。

普通货物 `E` 拿起、`F` 收入口袋，`Tab` 可再取到手中；口袋最多 4 个物品格。大矿由一人慢搬，另一人空手靠近，对准其手中的大矿按 `E` 协助，两人都要自己走动、保持接近。协助会明显提速，但不会自动拖着另一人的镜头走；在 `Tab` 点“退出协助搬运”即可退出。协助不自动分配售价。

把货实际运到收购台，`E` 打开后点所选物品的“出售”。成交价按界面显示，只有卖家收款；卖家按 `Tab` 输入金额，再点“确认转给某人”完成自愿分账，点击确认即支付。失败时看提示，别用反复点击代替确认结果。

当前默认数值如下，都是游戏币或游戏材料，不涉及真钱；物品数量不同会影响报价，旧营地的已保存公共目标以界面为准。

| 项目 | 当前默认数值 |
| --- | --- |
| 石料／铁料／金粒／沉重大矿，每件基础售价 | 3／12／55／140 游戏币 |
| 未全开原石售价 | 35 游戏币；开窗后仍按未全开价，全开后按实际矿芯报价 |
| 原石开窗／全开 | 3／5 游戏币 |
| 矿镐维修，任选一条 | 12 游戏币，或 1 铁料，或 3 石料 |
| 制作 1 段梯子 | 2 石料 |
| 个人矿镐升至 2 级并修满 | 180 游戏币 |
| 个人探测附件升至 1 级 | 90 游戏币 |
| 公共旧车与进阶道路修复总目标 | 400 游戏币 **加** 8 铁料，可分次自愿贡献 |

先留一些石料造梯、铁料修车。耐久降到零只会让矿镐变慢，基础工具不会永久消失；没钱仍能采集基础资源。河滩有独立碎矿，按营地在线活动时间约 10 分钟补充，不能据此期待深坑自动长回来。

## 朋友之间可以怎么闹

嘴藏仅限一颗小金粒，别人能看到鼓嘴。嘴里有矿时先 `B` 吐出，才能在 `Tab` 选择“抽烟斗”或“举瓶喝一口”；这些是角色表演，没有付费增益，`X` 可取消。空手更便于试这些动作。

默认允许近距离矿镐击晕：短晕约 2 秒，恢复后约 4 秒保护。手持货会掉，嘴中矿会吐出。近距离对准玩家按 `E` 可以做约 1 秒的搜袋动作，一次拿一个普通口袋格，不会清空余额或私人柜。先和朋友说好再试；有人不想参与，房主就切换和平营地。界面里的收购或加工菜单不会暂停攻击和世界。

拿到原石后可以直接卖、在物品菜单粗检，或去原石加工台付费开一个窗、全开。粗检线索只给本人，窗口状态可被别人看见；同一块石的内部内容固定，转手、藏起、重进都不重新抽奖。全开之后再卖或入柜收藏。

对赌时两人都到赌桌旁，各自选对手、一块尚未全开的原石和相同赌金，点击“提出／更新”，然后各自确认。改石头或金额会清除旧确认。双方最终确认后，钱与石进入托管，不能退出逃单；胜者拿两份赌金，平局退回各自赌金，**各自开出的矿芯仍回各自个人柜**。未锁定草案可取消；没有合适原石时继续挖或普通加工，不需要为了完成清单乱建新档。

## 修车，再去进阶矿坑

个人升级在营地的**维修台**：靠近并按 `E`，选择“升级矿镐并修满”或“升级探测附件”。个人升级与旁边旧车的公共修复分别付费，按界面所示游戏币确认。

到旧车旁公共维护点按 `E`，看还缺多少币和铁料，填入这次愿意交出的数量并确认。只扣贡献者自己的钱或携带的铁料，不自动均摊、不向离线朋友扣款。两项目标都满足后，全世界开放旧车和道路；个人工具仍要各自升级。

靠近已停稳的车按 `E` 打开菜单，把自己手中或口袋的货装进空货位，再空手选择驾驶座或乘客座。共 4 座、4 个公共货位；一位驾驶员控制，朋友自愿上车，没有上车的人不会被传送。

`W/S` 油门与倒车，`A/D` 转向；松开油门等车停稳，再装卸。**沿途任何停车处都能由附近下车的成员装卸，货架不是私人柜，也不限定在收购点卸货。** 卸下货要空手，并先退出大矿协助。驾驶员离开座位或断线后车会停下，另一人可以接手。

沿连接路抵达进阶坑，过窄口时摆正车身，在完整地面停车后下车，不要把车开进挖开的矿坑。面向北侧进阶区时，左侧一列普通岩层仍允许基础矿镐开挖；其他较硬岩层需要 2 级矿镐，以瞄准提示为准。工具升级提高采集能力，不会把每块矿都变成大奖。没赶上车的人也能在道路开放后步行前往。

返回时把货带回收购台再卖，不能直接卖远处货架上的矿。车卡住且无人乘坐时，可到营地维护点选择回收空车；所有人先站到停车位侧边，货物会留在车原来所在处，不能借回收远程运货。原车或停车位被障碍堵住时可能拒绝回收，保留提示并报告。

## 附近语音

游戏内语音已经接入，麦克风采集、编码、真实本机网络与DSP播放链经过自动验证。朋友的设备、网络和实际听感仍需两人核验；只有互相听见，才勾选本次条件下可用。声音居中播放并随距离衰减，当前没有左右方向声像。

入口为 `Esc` 菜单里的“附近语音 · 按住 V 说话”：选择“使用系统默认”或具体麦克风，必要时“刷新麦克风列表”，关闭“静音我的麦克风”，调整语音音量。点击“返回游戏”后按住 `V` 说话，松开即停；打开菜单或切出游戏不应继续发送。勾选“静音某人”只影响你本机听这位朋友，不会替所有人禁言；说话提示只能说明检测到活动，不能代替对方确实听见。

两人先戴耳机，在 3 米内互相说一句并复述，再一人走远：3—20 米逐渐变小，20 米及以外听不到；靠近后应恢复。双方交换角色，再试松开 `V`、静音、换设备和重新加入。无设备或权限不可用时记录提示，由本人处理系统麦克风授权；不要发送音频凭据或替别人点击授权。

至少有一轮在持续按住 `V` 说话时往返远近位置，确认回到近处后不用重新按键也能恢复。分别记录“甲能听见乙”和“乙能听见甲”，以及是否有回声、卡断或环境声盖过聊天；麦克风活动条、发送计数或测试音通过都不能代替真人双向交谈。

若当前包语音尚不可用，可临时用双方已有的外部通话继续早期玩法测试，但本次“游戏内双向语音”仍记未完成，不用外部通话冒充通过。

## 建议的一小时安排

时间是建议，不是强制进度；没挖到合适原石或钱还不够时照实记录，继续原营地，不为追清单重抽。

| 时间 | 一起做的事 | 留意什么 |
| --- | --- | --- |
| 0—5 分钟 | 同包进入、认名字和颜色；互相实听语音 | 真实设备数、连接条件、谁听得到谁 |
| 5—20 分钟 | 探测、争抢同一块矿、向下挖两层、搭梯返回 | 只能一人拿到同一块；坑可走进去、梯路可往返 |
| 20—35 分钟 | 单人搬大矿、双人协助、退出协助、运回卖出和转账 | 速度有差、分账可理解、入柜后别人拿不到 |
| 35—45 分钟 | 自愿试击晕／搜袋、藏嘴／吐出、烟斗／喝酒、原石加工与一局对赌 | 动作看得懂、保护期有效、赌金和矿芯去向正确 |
| 45—55 分钟 | 个人升级、分次修车、驾驶与乘坐、进阶采矿、沿途装卸和回营 | 未贡献者可用公共设施；基础工具左列仍有事做；货物不复制 |
| 55—60 分钟 | 一人先离开重进；最后房主正常保存结束，再继续同一营地 | 先离开者货物留包；钱、柜、矿坑、两层梯、车与道路进度仍在 |

请额外说说哪里卡住、哪里看不懂、是否想主动合作、是否愿意再挖一趟。不要只反馈“能运行”；没走到的流程写“未试玩”。

这次用几台电脑、几名真人、是否同一局域网，要单独记下。本机多进程、两台设备局域网、异网两人、异网四人和中国／美国组合是不同记录；前一项成功不能替后一项打勾。普通朋友试玩用正常菜单退出，不安排强杀房主或破坏存档，故障注入由制作者在隔离测试档完成。

## 存档、备份和换电脑

普通运行时，在 Windows 文件资源管理器地址栏输入：

```text
%USERPROFILE%\AppData\LocalLow\GoldCamp\GoldCamp
```

这里的 `Identity` 是**本人的稳定身份**，含私密的 `player.json`；`Camps` 是**本机作为房主保存的营地**，各营地有独立目录，内含 `world.camp.json` 与两个轮换备份。朋友加入别人的营地时，世界主档仍在那位房主电脑上。

备份请这样做：

1. 房主用菜单成功保存并结束，所有本机 GoldCamp 窗口都完全关闭。
2. 把整个 `Identity` 和整个 `Camps` 文件夹一起复制到自己保管的、带日期的新备份目录；尚未建过营地的朋友可能只有 `Identity`。
3. 换自己的电脑时同样先关游戏，先备份新电脑已有的这两个目录，再恢复本人配套的完整备份。不要将不同时间的营地文件拼起来，不要混用朋友的身份资料。

**备份留在自己手里，不发给试玩群。不要发送 `player.json`、其中的 `Secret`、整个存档或整个用户资料目录来报 bug。** 身份或营地读入失败时保留原件，请制作者协助核对；不要直接新建、覆盖或手改存档来“修好”。备份恢复会回到那个保存时刻，当前界面没有一键恢复或云同步入口。

如果读档提示从备份恢复，先记录提示并在关游戏后保留整套原件；如果提示存档版本更新，不要用旧游戏强行打开或把旧备份覆盖上去。同一营地目录不能同时由两个房主进程写入。制作者自动化产生的隔离测试档不属于这里的真人营地，也不应复制过来替换试玩进度。
