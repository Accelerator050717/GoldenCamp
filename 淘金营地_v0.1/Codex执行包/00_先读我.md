# GoldCamp：Codex 执行包 v0.1

这是一组项目工作模板，不是已经创建、编译或测试的 Unity 游戏工程。日期：2026-09-06。

## 使用顺序

先阅读《淘金营地_完整开发提案_v0.1.md》并把它作为设计基线。新建一个独立、可写的 GoldCamp 项目工作目录，不把文件混进现有网站、医疗或小程序项目。在 Codex 中打开这个目录，放入提案，然后提交 `01_M0_启动任务.md` 的全文。

AGENTS.md 是后续项目规则模板。让 Codex 根据 M0 查到的真实版本和实际命令补齐，不要凭模板声称脚本已经存在。每完成一个里程碑，用 `02_里程碑任务模板.md` 和 `03_M1至M6任务卡.md` 启动下一轮。未通过当前退出条件，不扩充后续内容。

登录、购买、二次验证、发行主体及正式上线仍由你本人操作。不要在仓库或聊天中贴密码、API key、Steam 账户令牌。工具不通时，先用编辑器脚本／命令行做等效最小验证，不要围绕工具本身无限折腾。

## 文件

- `AGENTS.md`：项目边界、验收与交接规则。
- `01_M0_启动任务.md`：可直接给 Codex 的首轮任务。
- `02_里程碑任务模板.md`：后续任务的固定结构。
- `03_M1至M6任务卡.md`：各阶段范围与通过条件。
- `04_资产规格与登记模板.md`：AI／人工资产进入游戏的规范。
- `05_测试与发布清单.md`：逻辑、多人、试玩与发布检查。

建议先让 M0 实际产生 `docs/STATUS.md` 和一个可运行构建。最早的成功不是一段漂亮汇报，而是你打开游戏后能走动、拿起并放下一块矿石。
