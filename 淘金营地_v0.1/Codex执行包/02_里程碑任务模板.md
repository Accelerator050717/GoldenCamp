# 单轮任务模板

## 当前基线

里程碑：M__。真实分支／commit：读取 Git 后填写。首先读取 AGENTS.md、docs/STATUS.md、DECISIONS.md、TEST_PLAN.md，交叉核对实际工程。不要要求我重讲已有背景。

## 本轮唯一目标

[用一句话描述玩家可观察的变化，不超过一个清晰的功能闭环。]

## 范围

必做：[具体行为和模块]。
不做：[本轮容易扩张的内容]。
保持不变：[已通过的核心行为、数据格式或兼容规则]。

## 验收

给出正常路径、失败路径、至少一项多人竞争／重试情境。对每项写清预期状态，不只写“正常运行”。
如果涉及钱／物品／存档，必须检查唯一性、交易守恒、重复请求和断线恢复。
如果涉及模型，必须在实际角色、碰撞和灯光中验证，不只看预览图。

## 执行

自行实施、debug 和运行所有受影响测试。先读并使用现有入口；入口不存在则创建并验证，不猜脚本参数。
发现与源码冲突的旧文档时修正文档，不按照旧报告覆盖正确实现。重大新设计记入 DECISIONS，附最短理由。

## Git 与发布权限

[明确本轮能否 commit；是否允许 push；远端与分支。默认不允许公开发布、收费购买和破坏性 Git 操作。]

## 输出

实际改动、运行证据、测试用例数和失败数、构建位置、未验证事项、下一步。同步 STATUS 和 TEST_PLAN。不要把将来工作写成已完成。
